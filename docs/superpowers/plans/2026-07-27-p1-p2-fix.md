# P1协程帧池修复 + P2 WS writev优化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** P1用线程局部单槽缓存减少协程帧malloc/free，P2用writev避免WS帧编码时的payload拷贝。目标：在P0(101μs)基础上再缩减5-15μs。

**Architecture:** P1在TaskPromiseBase::operator new/delete中增加单槽缓存，同大小帧复用，不同大小先清理再分配。线程局部存储保证无锁安全。P2在write_frame中始终使用writev(iov[2])：帧头栈编码(≤14B)+payload原位引用，避免encode_into的完整拷贝。

**Tech Stack:** C++20 coroutines, io_uring, thread_local, header-only

## Global Constraints
- 遵守CLAUDE.md全部规范
- P1只用单槽缓存避免ABI（不引入新类型/文件）
- P2必须保证iov[1]引用的frame.payload在Writev操作期间存活（send_text中临时FrameT在协程帧中）
- 每次改动后运行GTest 120 + ws_bench 2000msg
