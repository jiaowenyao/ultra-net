# P1协程帧池 + P2 WS帧writev优化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 通过协程帧单槽缓存(P1)和WS帧writev零拷贝(P2)，将WS Echo延迟从101μs缩小至接近raw io_uring的81μs。

**Architecture:** P1在TaskPromiseBase中增加线程局部单槽帧缓存，避免重复malloc/free。P2将write_frame的栈编码路径改为writev发送帧头+payload，消除encode_into的内存拷贝。

**Tech Stack:** C++20 coroutines, io_uring, header-only library

## Global Constraints

- 遵守 CLAUDE.md: 注释中文化、禁止压行、禁止std::cout、ASAN验证、GTest测试
- P1 必须避免ABI问题：只重载 `operator delete(void*)`（不带size_t），用单独size变量匹配
- P2 必须保持大帧(>16KB)的现有writev路径不变
- 每次改动后运行: GTest 120 + ws_bench (2000msg单连接)
